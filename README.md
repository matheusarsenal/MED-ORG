## 📌 Sobre o Projeto

O **MED-ORG** é um projeto acadêmico de desenvolvimento de software voltado à área da saúde, com o objetivo de facilitar o acesso a informações e serviços médicos por meio de uma plataforma digital.

A proposta busca conectar **pacientes, profissionais de saúde e unidades médicas**, oferecendo recursos para localização de estabelecimentos, consulta de especialidades, agendamento de atendimentos e acompanhamento médico.

O projeto contempla atividades de desenvolvimento de interfaces, integração com banco de dados, modelagem de sistemas e organização de tarefas utilizando metodologias ágeis.

### 🌱 Objetivo de Desenvolvimento Sustentável

O MED-ORG está relacionado ao **ODS 3 — Saúde e Bem-Estar**, que busca assegurar uma vida saudável e promover o bem-estar.

## 🎯 Objetivos

### 👤 Para Pacientes

- Facilitar a busca por unidades de saúde.
- Consultar especialidades médicas disponíveis.
- Acompanhar informações sobre consultas.
- Simplificar o processo de agendamento.
- Facilitar a comunicação com profissionais de saúde.

### 👨‍⚕️ Para Profissionais de Saúde

- Disponibilizar informações sobre suas especialidades.
- Organizar horários e locais de atendimento.
- Facilitar a comunicação com pacientes.
- Acompanhar informações relacionadas aos atendimentos.

### 🏥 Para Unidades de Saúde

- Organizar informações sobre serviços disponíveis.
- Consultar registros de pacientes e profissionais.
- Melhorar os processos de atendimento.
- Explorar possibilidades de automação de atividades administrativas.

---

## 📱 Funcionalidades Previstas

As funcionalidades abaixo representam os objetivos e recursos planejados para o sistema.

### 🗺️ Localização e Informações

- Visualização de unidades de saúde por meio de mapas.
- Localização de estabelecimentos utilizando GPS.
- Consulta às especialidades disponíveis.
- Informações sobre profissionais vinculados às unidades.
- Consulta à disponibilidade de profissionais.
- Possibilidade de emissão de senhas para atendimento.

### 📅 Consultas e Atendimento

- Agendamento de consultas médicas.
- Acompanhamento de informações sobre atendimentos.
- Disponibilização digital de prescrições médicas.
- Comunicação remota entre pacientes e profissionais.

### ⚙️ Automações Propostas

- Envio de e-mails de confirmação de consultas.
- Compartilhamento digital de prescrições.
- Atualização da presença de médicos nas unidades.
- Integração com sistemas de identificação por crachá.

> **Observação:** O registro de entrada e saída por crachá foi proposto para atualizar a disponibilidade dos profissionais nas unidades de saúde.

### 🏃 Desenvolvimento por Sprints

O desenvolvimento foi organizado em sprints, permitindo acompanhar as atividades, dificuldades e soluções encontradas.

#### Sprint 1 — Definição e Desenvolvimento Inicial

Durante a primeira sprint, a equipe enfrentou dificuldades de comunicação relacionadas à escolha das tecnologias.

Houve dúvidas sobre a utilização de React Native e HTML, além de desafios associados à emulação da aplicação para dispositivos móveis.

#### Sprint 2 — Desenvolvimento e Testes

Na segunda sprint, foram identificadas dificuldades relacionadas às tecnologias de desenvolvimento.

Como alternativa, a equipe utilizou React para Web para realizar testes e avançar na construção das interfaces.

#### Sprint 3 — Integração com Backend

Na terceira sprint, o principal desafio foi a integração entre frontend, backend e banco de dados.

A equipe trabalhou com PHP e MySQL, enfrentando dificuldades iniciais devido à pouca experiência com PHP.

Esse processo contribuiu para o aprendizado de integração entre diferentes tecnologias.
